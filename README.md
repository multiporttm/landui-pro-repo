# LandUI Pro

LandUI Pro is a variable sans-serif for user interfaces, by Multiport. It is derived from [Inter](https://github.com/rsms/inter), with a distinct default look: single-storey a, tailed l, serifed capital I, slashed zero, open numerals and round quotes.

![LandUI Pro compared with Inter](documentation/landui-pro-vs-inter.png)

## Files

- `fonts/variable/LandUIPro[opsz,wght].ttf`: variable TrueType font
- `fonts/webfonts/LandUIPro[opsz,wght].woff2`: the same font as WOFF2 for the web
- `scripts/design.py`: build step that takes the Inter variable font and makes a chosen set of Inter's alternate glyphs (cv05, cv06, cv08, cv10, cv11, cv12, cv13, zero, ss01, ss03, ss07) the defaults
